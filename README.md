# CS 250 — Agile Delivery and Java UI Portfolio

This portfolio presents an Agile delivery case study alongside a small Java Swing slideshow implementation. It demonstrates how user stories, test cases, Scrum roles, sprint review, and retrospective feedback connect to a working increment.

## What this demonstrates

- Writing user stories and acceptance-oriented test cases
- Collaborating through Scrum roles and team agreements
- Using sprint review and retrospective feedback to improve delivery
- Packaging a Java Swing interaction as a runnable project
- Separating process evidence from implementation evidence

The original Office assignments and scenic image assets remain private pending metadata, licensing, and attribution review.

## Source

`src/SlideShow.java` is a cleaned copy of the verified Java implementation. It expects five local image resources under `/resources`; those images are intentionally not included until their rights are confirmed.
